# ویرایشگر عکس — Rust + Tauri

ویرایشگر و روتوش عکس برای ویندوز، الهام‌گرفته از **PhotoInstrument**
(https://www.photoinstrument.com/) — با موتور Rust و رابط Tauri v2.
عکس‌ها فقط روی همین کامپیوتر پردازش می‌شوند و به اینترنت فرستاده نمی‌شوند.

## ابزارها

- **باز کردن / ذخیره:** پنجره انتخاب فایل، کشیدن و رها کردن، ذخیره JPG / PNG / BMP / GIF
- **روتوش:** صاف کردن پوست (Glamour Skin)، پاک کردن لک (Healing Brush)، حذف شیء (Object Removal)
- **کلون، محو (Smudge)، تغییر فرم (Liquify)** — قلم تا ۵۰۰ پیکسل
- **Dodge / Burn، تاری و وضوح قلمی، رنگی کردن (Colorize)**
- **چشم قرمز:** کلیک روی چشم قرمز
- **نور و رنگ (Rust):** روشنایی، کنتراست، اشباع، گرما، چرخش رنگ، تاری، وضوح، سطوح رنگ، درخشش (Glow)، نویزگیری (Denoise)
- **برش، چرخش، چرخاندن، تغییر اندازه (Scale) و تغییر اندازه گروهی (Batch Resize)**
- **متن و لایه‌ها:** متن به‌عنوان لایه، لایه عکس، شفافیت، حذف و ادغام لایه‌ها
- **فیلترها:** گرم، سرد، سیاه‌سفید، قدیمی، زنده
- **واگرد / از نو (Undo / Redo)** و بزرگنمایی

## اجرای محلی (توسعه)

```bash
# ۱) نصب Rust از https://rustup.rs
# ۲) نصب Node.js 20
npm install
npm run tauri dev
```

## ساخت فایل exe ویندوزی

ساخت exe باید روی ویندوز انجام شود؛ GitHub Actions این کار را می‌کند:

```bash
git tag v1.0.0
git push origin v1.0.0
```

بعد از ساخته شدن، فایل نصب‌کننده (`.exe` از NSIS و `.msi`) را از بخش
**Releases** همان ریپو یا از **Actions → Artifacts** دانلود کنید و نصب کنید.
برای ساخت دستی بدون تگ هم می‌توانید از تب Actions گزینه **Run workflow** را بزنید.

## ساختار

```
src/                  رابط کاربری (HTML/CSS/JS، فارسی و راست‌چین)
src-tauri/
  src/main.rs         دستورهای Rust: دیالوگ فایل، تنظیم نور/رنگ، نویزگیری،
                      تغییر اندازه، تبدیل GIF، انتخاب پوشه
  tauri.conf.json     تنظیمات برنامه (نام، آیکون، پنجره ۱۲۸۰×۸۰۰)
  capabilities/       دسترسی‌های Tauri (dialog و fs)
```
